# Промт для Claude: работа с интерфейсом Genix (обязателен)

Источник правды по виду — `docs/design/genix-design-system.html`. Открывай и сверяйся с ним перед любой правкой интерфейса.

## 1. Номера
- Каждая кнопка имеет номер `B01`–`B15`, каждый интерактивный элемент — `I01`–`I06`.
- Пользователь называет номер («на регистрацию B01, под ней B03») — используй **ровно его**. Не подменяй «похожим».
- Номер не назван — выбери по таблице «Правила» в HTML и **напиши в ответе**, какой номер поставил и где.
- В Rust каждая функция вида в `crates/app/src/ui_kit.rs` называется по номеру (`b01`, `b02`, …) и в doc-комментарии повторяет номер и назначение. Новую кнопку без номера не создаём: сначала добавляем её в HTML и получаем «да» от пользователя.

## 2. Проверка до сдачи (без этого не сдавать)
1. `cargo test --workspace --offline`, `cargo build --release --offline` — без предупреждений.
2. QA-копия с **другим** идентификатором (`CFBundleIdentifier` = `com.danielkrinets.genix.qa`) и `GENIX_SETTINGS_PATH` во временной папке: настоящий профиль пользователя не трогать.
3. Скриншоты экранов, которые менялись: окно 1360×892 и узкое 900 px; светлая и тёмная темы. Искать: обрезанные и уехавшие за край кнопки, наложения, пустые провалы.
4. Главное действие никогда не лежит в прокручиваемой области.

## 3. Дисциплина
- Дизайн не менять без просьбы. Flat iOS 18: заливка, радиус, без обводок и градиентов. Белый текст на акценте.
- Не заменять приложение веб-интерфейсом. HTML — только описание вида.
- Ответы короткие, по-русски, со скриншотами. Честно говорить, что не проверено.
- Работать этапами, на каждом — тесты и коммит. Секреты подписи Apple не трогать, пока пользователь не скажет.

## 4. GitHub (не забывать)
- После каждого этапа отправлять изменения в **ветку** (не в `main`): `git push origin feature/backgrounds`.
- Любой push запускает сборку, которая перезаписывает релиз `genix-latest`. Поэтому в последнем коммите ветки — `[skip ci]`. В `main` — только проверенное и по слову пользователя.

## 5. Интерактив
- Монстр-слизь `I01`: следит за курсором, отворачивается при вводе пароля, масштабируется с окном.
- Фон из букв `I02`: реагирует на мышь, не перехватывает ввод, при «уменьшить движение» замирает.
- Подсказка `I03`, билет `I04`, папка `I05`, дерево с ветками `I06`.
