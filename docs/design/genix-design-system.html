Как этим пользоваться

У каждой кнопки и каждого интерактивного элемента есть номер (B01, I02…). Говори мне «на регистрацию — B01, под ней — B03», и я использую именно этот вариант. Новые кнопки без номера из этой страницы я не придумываю.

Кнопки

Плоские, без обводок и градиентов: заливка, радиус, одно состояние нажатия (сжатие 3 %, 160 мс). Наведение — на 1 ступень светлее. Белый текст на акценте.

Интерактивные элементы

Живые детали Genix. Они подчинены работе с моделью: не мешают вводу, при «уменьшении движения» замирают.

Пункт боковой панели

Иконка 20 в плитке 42 px. Выбранный — сплошной accent и белая иконка (чтобы не сливался с фоном). Панель только сворачивается кнопкой сверху, по наведению не раскрывается.

Один тёмный ряд: лупа слева, «Фильтры ▾» текстом справа, без овала. Крестик очистки появляется при вводе.

B18

Большая «+» на фоне

Круг 60 px в правом нижнем углу библиотеки. Нажатие разворачивает «Новая модель» и «Новая папка», каждый пункт спрашивает имя. Тот же выбор есть в меню «Файл».

I07

Режим перемещения

Shift+клик по модели или удержание на пустом месте 0,6 с: карточки дрожат, на них кружки выбора, сверху «Выбрано: N → папка», Готово. Карточку можно перетащить на папку.

I08

Вращение по наведению

Курсор на карточке модели 3 секунды — превью крутится на 360° (24 кадра). В памяти держатся последние 4 модели.

I09

Палитра команд ⌘K

Поиск по всем действиям; недоступные серые; ↑↓ выбор, Enter запуск, Esc закрыть.

Правила

  • Основное действие экрана — одна кнопка B01. Рядом не больше одной B02.
  • Ссылки и «Отмена» — B03. Всё необратимое — B04, и только после подтверждения.
  • Значки без подписи — B05/B06 с подсказкой I03. Включённое состояние — тонировка акцентом, а не сплошная синяя плашка.
  • Панели инструментов — B07. Фильтры и теги — B08. Переключатель видов — B09.
  • Панель не должна обрезать кнопку: главное действие закрепляется справа и не уезжает в прокрутку.
  • Радиусы: кнопка 12–14, таблетка половина высоты, карточка 20, поверхность 22, пункт меню 6.
