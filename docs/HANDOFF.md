## ВАЖНО про CI
`.github/workflows/genix-build.yml` запускается на любой push и перезаписывает релиз `genix-latest`. Непроверенное пушить с `[skip ci]` в последнем коммите (или в ветку). В `main` — только проверенное. Секреты подписи (`IOS_CERT_P12`, `IOS_CERT_PASSWORD`, `IOS_PROFILE`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8`, `MAC_CERT_P12`, `MAC_CERT_PASSWORD`) пользователь ещё не добавил; аккаунт Apple Developer рабочий — сначала уточнить, можно ли выпускать от имени компании. Нужны права Admin/App Manager, а Developer ID создаёт только Account Holder.

## Как тестировать приложение в Linux
```sh
Xvfb :99 -screen 0 1400x850x24 &   # DISPLAY=:99
GENIX_SETTINGS_PATH=/tmp/set.json GENIX_SKIP_LOGIN=1 target/release/genix &
xdotool search --name Genix  →  xdotool windowfocus <id>     # иначе нет клавиатуры
xwd -root | convert xwd:- shot.png
```
Для сценариев см. `tools/demo/drv.py`. Тесты: `cargo test --workspace` (55 + 65 проходят, один тяжёлый пропущен).
