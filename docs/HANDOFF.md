## Замечания пользователя по интерфейсу (скриншот: сетка папок на главной) — ЕЩЁ НЕ СДЕЛАНО
Уточнения пользователя (после первой версии этого файла):
- «Линия, с которой начинается объект» — это **левый край**: у одних элементов он правее, у других левее. Это **не разное время появления**. Проблема есть почти по всему интерфейсу, не только в папках.
- «Баг-иконка» — значок **bug** у кнопки «Сообщить о проблеме» (не STL; прежнее прочтение «stl*» было неверным).
- «Слайдер» — левая навигационная панель (подтверждено «yes-yes»).

**Найденная причина (по коду, ещё не исправлено):**
1. `home.rs`, `folders_section` (~стр. 1250): `ui.horizontal_wrapped` + `ui.add_space(22.0)`. В wrapped-раскладке отступ получает только первая строка, вторая начинается от нуля — на скриншоте ряд 1 стоит на x≈75, ряд 2 на x≈33 (разница ≈ 22 pt). Заголовок «Папки» при этом отступает на 24, карточки на 22. Рядом уже есть правильный приём — `egui::Frame::NONE.inner_margin(Margin { left: 22, .. })` (стр. 971, 1015).
2. По `home.rs` разбросаны жёсткие `add_space(22.0)` / `add_space(24.0)` (≈23 места: стр. 492, 557–598, 648–719, 780–819, 883, 953–966, 1012, 1222, 1247–1252, 1280, 1321) и `add_space(20.0)` (1094). Нужна **одна константа левого поля** (например `CONTENT_LEFT`), применённая через `Frame::inner_margin`, а не через `add_space` внутри `horizontal_wrapped`. Затем пройти все экраны (главная, папки, фильтры, поиск, настройки, профиль, подписка, редактор) и сверить левую линию.
3. Вертикальная розово-серая полоса на x≈75–88 поверх первой папки (видна и поверх «Новая папка 5») — источник не найден; проверить, не рисуется ли что-то в `home.rs` / `backgrounds.rs` / полосе прокрутки / индикаторе навигации.

Что нужно сделать:
1. Единый левый край (см. выше) — **главное замечание**.
2. Кнопка «Сообщить о проблеме» и значок bug выровнены с остальными кнопками (левый край/базовая линия).
3. Панель фильтров поиска не должна идти раньше строки поиска: порядок «поиск → фильтры».
4. Папки создаются мгновенно, без анимации — добавить анимацию появления (160 мс, из текущего значения, при reduced motion без пространственного движения).
5. Боковая панель: убрать кнопку скрытия названий, подписи всегда видны.
6. Фильтры поиска: между чекбоксом и текстом нулевой зазор — отступ из системы спейсинга (`DESIGN.md`).
7. Свериться с kit `B01–B15, I01–I06` в `docs/design/genix-design-system.html`.
