# Проверка дома: что нажать и что должно получиться

Приложение: `~/Downloads/Genix.app` (коммит 7b908f0, ветка `feature/backgrounds`). Первый запуск: правый клик → «Открыть». Подпись локальная, не Apple.
Ничего не отправлено в `main`, релиз GitHub не тронут.

Если пункт не получился: сделай скриншот и напиши номер. Я правлю по номерам.

## Уже проверено мной глазами (быстро убедись)
1. Заставка при первом запуске после обновления: логотип, полоса, «Добро пожаловать». Чтобы увидеть снова, удали строку `splash_seen` в `~/Library/Application Support/Genix/settings.json`.
2. Регистрация: монстр заполнен, отвернулся при вводе пароля, без рук. Слово Genix с тонким ободком.
3. Библиотека: поиск с «Фильтры ▾» внутри, большая «+» справа внизу.
4. «+» → «Новая папка» → окно имени → «Создать».
5. ⌘K открывает палитру команд.
6. Папка изнутри: три строки настроек (название, тумблер автосохранения, удалить).
7. Team, «Сервер» с билетом, «Настройки».

## Не проверено мной: нужны клики

### Библиотека
8. **Переименование папки:** правый клик по папке → «Переименовать…». Поле «Название» внутри папки получает фокус; Enter сохраняет.
9. **Режим перемещения:** Shift+клик по модели (или удержи мышь на пустом месте 0,6 с). Карточки дрожат, на них кружки выбора, сверху «Выбрано: N → папка», «Готово».
10. **Перетаскивание:** в режиме перемещения перетащи карточку на папку, папка получает рамку, модель уходит в неё.
11. **Вращение:** наведи на карточку модели и не двигай мышь 3 секунды: превью крутится на 360°.
12. **Поделиться:** правый клик по модели → «Поделиться…»: окно, почта, права, «Добавить», «Убрать».
13. **Правый клик по пустому месту библиотеки:** меню «Новый проект, Открыть файл, Создать папку, Режим перемещения, Фильтры, Настройки».
14. **Новая модель:** «+» → «Новая модель» → имя → вкладка называется этим именем, в окне «Сохранить» то же имя.

### Верхняя панель и меню
15. **Группы вкладок:** открой 2–3 вкладки, правый клик по вкладке → «В новую группу». Цветная метка с названием, клик по ней сворачивает группу, правый клик по метке: имя, цвет, «Разгруппировать».
16. **Меню «Файл»:** на пустом документе «Сохранить», «Экспорт STL/3MF», «Открыть в слайсере» серые. «Новая папка…» и «Новая модель…» открывают окно имени. «Версии файла» появляется после второго сохранения.
17. **Слайсеры:** открой пример «Кронштейн» → «Файл → Открыть в слайсере»: установленные программы доступны, остальные серые с пометкой.

### Редактор
18. **Поля над моделью:** «Выдавить», «Отверстие», «Скругление», «Вытянуть грань» показывают поля значений сверху окна модели.
19. **Вытянуть грань:** «Вытянуть грань» → щёлкни верхнюю грань → +5 добавляет, −5 вдавливает.
20. **Контекстное меню в окне модели:** правый клик: Новый чертёж, Выдавить, Отверстие, Скругление, Фаска, Вытянуть грань.
21. **Контекстное меню в чертеже:** правый клик в режиме чертежа: Линия, Прямоугольник, Окружность, Размер, Завершить, Отмена.
22. **Панель чертежа:** группа «Размеры» (Размер, Угол) видна справа от «Править»; если обрезана, прокрути панель.

### Прочее
23. **Ползунок «Масштаб интерфейса»** в настройках: при движении ничего не дёргается, масштаб применяется при отпускании.
24. **Загрузка из Finder:** двойной щелчок по `.genix` в Finder: короткая плашка «Открываем проект…».
25. **Материалы:** выбери тело, смени материал на «Нерж. сталь» или «Латунь»: на отверстиях и скруглениях должны быть заметные отражения.
26. **Демо-модель:** открой `docs/demo/ipad-mini-6-stand.genix` (подставка для iPad mini 6, 9 шагов) и покрути.

## Что менять, если не нравится
- Кнопки: назови номер из `docs/design/genix-design-system.html` (B01–B18) и где его поставить.
- Любая проверка выше: номер пункта и скриншот.

27. **Поставить на плоскость:** «Править → Поставить на плоскость» → щёлкни грань тела → выбери плоскость (XY/XZ/YZ), «С обратной стороны» при необходимости → OK. Грань ложится на плоскость, тело остаётся по другую сторону. Проверено мной: кнопка, выбор грани, OK для XY; XZ/YZ и флажок — только юнит-тестом.
