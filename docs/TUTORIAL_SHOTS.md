# Список скриншотов для мини-туториала Genix

Каждый пункт — один кадр (окно 1360×892, тёмная и светлая тема по желанию). Подписи кадров даю на русском, названия файлов — `NN-тема.png`.

## Первое знакомство
1. **01-splash** — заставка при первом запуске: логотип, полоса загрузки, «Добро пожаловать · v0.1.0». Чтобы увидеть заново, удали `splash_seen` в `~/Library/Application Support/Genix/settings.json`.
2. **02-registration** — регистрация: форма справа, слева слизь-монстр под словом Genix. Курсор в середине окна.
3. **03-mascot-away** — то же, но курсор в поле «Пароль»: монстр отвернулся.
4. **04-library** — «Мои модели»: кнопка «Новый проект», поиск с «Фильтры ▾» внутри, папки, карточки.

## Библиотека
5. **05-filters** — открыть «Фильтры ▾», отметить пару галочек.
6. **06-folder-create** — нажать «Создать папку» (пустое имя даёт «Новая папка»).
7. **07-move-mode** — удержать мышь на пустом месте 0,6 с или Shift+клик по модели: карточки дрожат, на них кружки выбора, сверху панель «Выбрано: N → папка».
8. **08-drag-to-folder** — перетащить карточку на папку, папка подсвечена рамкой.
9. **09-folder-view** — внутри папки: крупная кнопка «← Все модели» и список настроек (название, автосохранение на сервер, удалить).
10. **10-spin-preview** — навести на карточку на 3 секунды: модель вращается на 360°.
11. **11-share** — правый клик по модели → «Поделиться…»: окно с почтой и правами.
12. **12-context-library** — правый клик по пустому месту библиотеки: меню действий.

## Редактор
13. **13-editor** — общий вид: верхняя панель с вкладками, инструменты, дерево с ветками, нижняя панель вида.
14. **14-tab-groups** — две-три вкладки; правый клик по вкладке → «В новую группу»; цветная метка группы.
15. **15-new-sketch** — «Новый чертёж»: выбор плоскости XY/XZ/YZ.
16. **16-sketch-tools** — панель чертежа: инструменты, «Отмена» и «Завершить чертёж» закреплены справа.
17. **17-sketch-dimension** — прямоугольник с размерами и окно ввода значения.
18. **18-extrude-value** — «Выдавить»: поле «Расстояние» над моделью.
19. **19-press-pull** — «Вытянуть грань»: щёлкнуть грань, ввести −5 и +5 (оба направления).
20. **20-hole** — «Отверстие» с привязкой к центру грани.
21. **21-fillet** — скругление рёбер, поле «Радиус» над моделью.
22. **22-material** — панель свойств тела: цвет, отражение, масса.
23. **23-context-editor** — правый клик в окне модели: шесть главных действий.
24. **24-menu-disabled** — меню «Файл» на пустом документе: «Экспорт…» серые.

## Печать и экспорт
25. **25-export** — «Файл → Экспорт STL / 3MF».
26. **26-open-in-slicer** — «Файл → Открыть в слайсере» со списком (недоступные — серые).

## Аккаунт и сервер
27. **27-team** — вкладка Team: добавить человека, список.
28. **28-server** — «Сервер»: кнопка покупки (мок), затем билет.
29. **29-ticket-tear** — потянуть корешок билета: оторванный кусок, «Активирована (демо)».
30. **30-settings** — настройки: тема, акцент, ползунок масштаба интерфейса (двигается плавно, применяется при отпускании).

## Дополнительно
31. **31-photo-to-sketch** — «Фото → скетч»: картинка превращается в контуры.
32. **32-finder-open** — двойной щелчок по `.genix` в Finder: плашка «Открываем проект…».
33. **33-ipad-stand-final** — готовая подставка для iPad mini 6 (`docs/demo/ipad-mini-6-stand.genix`) с вращением.
