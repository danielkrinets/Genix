# Запись демо-ролика (Linux, виртуальный экран)

Скрипты ведут приложение через `xdotool` и пишут экран через `ffmpeg x11grab`; подписи накладываются из SRT.

```sh
sudo apt install xvfb xdotool ffmpeg imagemagick x11-apps
Xvfb :99 -screen 0 1400x850x24 &
cargo build --release -p fusion-app
mkdir -p /tmp/genix_demo && cd tools/demo && python3 demo.py       # пишет raw.mp4 и demo.srt в GENIX_DEMO_DIR
```

Подводные камни:
- Без оконного менеджера приложению нужно явно дать фокус: `xdotool windowfocus <id>` (функция `focus()`), иначе клавиатура не работает.
- Клавиши `xdotool type` с минусом: `type -- "-1"`.
- Редактор открывается на вкладке «Без имени» после «Новый проект» не всегда сам — скрипт кликает по вкладке.
- «Обратное направление» в выдавливании меняет знак расстояния; вводить глубину нужно ДО нажатия.
- Координаты кликов заточены под окно 1360×850 в Xvfb 1400×850; при другом размере поправьте.
- Камера: `F` — показать всё, левая кнопка — вращение, правая — сдвиг, колесо — масштаб.
- Подписи: после записи сдвинуть SRT на ~1,3 с и вжечь `subtitles=...:force_style='FontSize=7,...'` (размер масштабируется от 288 строк).
