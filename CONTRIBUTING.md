# Как помочь Genix

## Сборка и проверка

```
cd fusion
cargo run --release -p fusion-app      # запуск
cargo test --workspace                 # тесты
```

Нужны Rust, CMake и компилятор C++ (см. README). Перед отправкой изменений прогоните тесты.

## Устройство

- `crates/core` — ядро без интерфейса: выражения, чертёж и решатель, тела (Manifold), документ с историей, экспорт. Покрыто тестами — новую геометрию начинайте с теста здесь.
- `crates/app` — окно на egui/wgpu: рендер, камера, режим чертежа, диалоги команд, главная страница.
- `crates/app/assets/icons` — значки 24×24 (SVG из Figma, имя файла = id инструмента, список — `ICONS.md`).
- Тексты интерфейса пишутся по-русски и оборачиваются в `tr("…")`; английский — в `i18n_en.rs`, иврит — в `i18n_he.rs` (нет перевода — показывается английский).

## Правила

- Каждая кнопка в меню должна работать: без «заглушек» и декоративных элементов.
- Ограничения ядра честно описываются в README, а не скрываются.
- Коммиты — по одной понятной теме.
